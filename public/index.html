Demonstration and Testing Guide

Step-by-step procedures to demonstrate vulnerability exploitation and defense verification.

Scenario 1: SQL Injection Demonstration

  1. Select VULNERABLE mode in the upper right switcher.
  2. Navigate to SQL Injection tab and click the admin' -- button on the login form.
  3. Click "Attempt Login". The system grants administrative access without requiring a valid password. Notice the raw SQL executed in backend logs.
  4. Go to the product search form, click Exfiltrate Users Table via UNION, and execute search. User credentials and password hashes are dumped into the results.
  5. Switch system mode to SECURE and repeat both attacks. The parameterized queries and input validation strictly reject and block the attempts.

Scenario 2: XSS and Cookie Theft Demonstration

  1. Under VULNERABLE mode, open the Cross-Site Scripting tab.
  2. Select img onerror Alert or script Alert Cookie and submit comment.
  3. The browser immediately triggers the alert popup, confirming arbitrary JavaScript execution from database persistence.
  4. Switch to SECURE mode and reload the comments.
  5. Notice that the script tags are properly HTML entity encoded and rendered safely as text without execution. Furthermore, the session cookie is protected with the HttpOnly attribute.

Scenario 3: Security Telemetry and Audit

  • Open the Security Audit Logs tab to inspect all real-time incident records.
  • Each entry contains timestamp, source IP, endpoint, severity, action taken (EXPLOITED vs BLOCKED), and full payload details.
  • Demonstrates compliance with OWASP Security Logging and Monitoring requirements.
